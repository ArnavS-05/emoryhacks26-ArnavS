### Flakiness found and fixed
- The demo E2E failed 3/4 runs once Tiger Data (remote) was connected: the clinician panel's initial fetch could overwrite live WebSocket presence ("Patient not connected"). Fixed; 5/5 consecutive passes afterwards.
- A new question arriving while confirmed speech was still "playing" left scanning paused in browsers that never fire `onend`. Fixed: new questions cancel speech.

## Live Gemini document extraction (fictional documents)

`tests/fixtures/synthetic_prescription.png` (generated by `scripts/make_synthetic_documents.py`) → `gemini-3.5-flash`, 15.6 s, **9/9 fields correct** (2 allergies with reactions, 3 medications with sig/qty/refills, 2 conditions, 2 history items), each with a verbatim source excerpt and confidence 0.98, all stored **unverified**.

`tests/fixtures/synthetic_medication_list.pdf` → 8.5 s, **6/6 fields correct**. Uploading it to the wrong patient now triggers a wrong-patient warning.

## Static board vs Synaphi benchmark

`/clinician/benchmark` measures **human-performed** tasks (time, selections, incorrect selections, retrieval latency) on a static category board vs Synaphi's contextual board and stores them as benchmark events. **No human benchmark results are reported here yet** — automated clicks would not be meaningful. Run it with real participants before quoting numbers.
